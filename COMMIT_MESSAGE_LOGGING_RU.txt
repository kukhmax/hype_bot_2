chore(logging): уменьшить шум и добавить ключевые этапы процессов

Что сделано
- Изменён базовый уровень логов:
  - LOG_LEVEL по умолчанию теперь INFO вместо DEBUG;
  - DEBUG остаётся доступен через переменную окружения для детальной диагностики.
- Свечи и Redis:
  - сохранение свечи в Redis переведено с INFO на DEBUG, чтобы не засорять лог раз в минуту на каждый инструмент/TF.
- Подписки и первичный расчёт:
  - при создании подписки логируем начало загрузки истории и её итоговый объём;
  - добавлен INFO-лог «Анализируем историю по ML Supertrend…» перед первичным расчётом;
  - сохранили итоговый INFO по результату расчёта (LONG/SHORT/нет сигнала).
- WebSocket:
  - после подписки allMids добавлен INFO «Начинаем отслеживать цены через WS для подписанных пар»;
  - вместо постоянного DEBUG по тикам добавлен редкий INFO-пример тика (раз в 5 минут) для контроля, что поток живой.

Файлы
- app/core/logger.py — базовый уровень логирования по умолчанию INFO.
- app/services/candles.py — лог сохранения свечи переведён на DEBUG.
- app/services/subscription_service.py — INFO-этапы загрузки и анализа истории по ML Supertrend.
- app/services/market_ws.py — INFO-логи подключения и периодический пример тика из WS.
