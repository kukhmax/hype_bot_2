# Fibo Bot 🤖📈

Асинхронный торговый бот для криптовалютной биржи MEXC, построенный на базе Теории Волн Эллиотта, уровней Фибоначчи и машинного обучения. Бот автоматически ищет торговые сетапы, фильтрует их риск-менеджментом, проверяет через ансамбль ML-моделей и присылает итоговые сигналы с графиками в Telegram.

## Основной функционал

- **Market Engine**: Подключение к бирже MEXC через WebSockets (real-time stream) и REST API (для прогрева исторических данных). Автоматическое агрегирование 1m свечей в любые старшие таймфреймы.
- **Feature Engine**: Вычисление десятков индикаторов и признаков рынка "на лету" (ATR, RSI, ADX, VWAP с Z-score, Bollinger Bands, паттерны свечей и объемов, определение торговой сессии и тренда).
- **Strategy Engine**: Умный поиск разворотных точек:
  - Определение рыночного режима (Trend UP, Trend DOWN, Range).
  - Поиск Импульса (Wave 1) не менее 2.5 средних ATR.
  - Поиск откатного движения (Wave 2) строго в зону Фибоначчи `0.5 - 0.618`.
  - Поиск пробоя структуры (Structure Break) в зоне Фибоначчи как триггера для входа.
- **Risk Engine**: Строгий контроль рисков: защита от аномальной волатильности, блокировка стратегии при достижении дневного лимита убытков (PostgreSQL), лимит одновременно открытых сделок (Redis), автоматический расчет размера позиции в % от депозита на основе Stop Loss.
- **ML Engine**: "Нулевой запуск" (Zero-to-One). Оценка вероятности отработки сигнала до Take Profit. Под капотом взвешенный ансамбль из XGBoost, LightGBM и Logistic Regression с калибровкой вероятностей (`CalibratedClassifierCV`). В комплекте скрипт для авто-разметки датасета на истории с биржи и первичного обучения моделей.
- **Telegram & Charts**: Отправка красивых HTML-сигналов администратору. К каждому сигналу прикрепляется график свечей (mplfinance) с отрисованными уровнями VWAP, EMA, зоны входа и линиями Stop/TakeProfit. Кнопочное меню для управления ботом прям из мессенджера.

## 🛠 Установка и Настройка

### Требования
- Окружение Linux (рекомендуется Ubuntu).
- Установленный `Docker` и плагин `docker-compose`.

### Шаг 1. Клонирование и конфигурация
```bash
git clone <ваш-репозиторий>
cd fibo_bot
```

### Шаг 2. Настройка `env`
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте файл `.env` любым текстовым редактором и заполните ключевые поля:
- `MEXC_API_KEY` и `MEXC_API_SECRET` — ключи доступа биржи.
- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram бота (от @BotFather).
- `TELEGRAM_ADMIN_IDS` — ваш Telegram ID (чтобы бот реагировал только на вас).

## 🚀 Запуск и Логи

Бот завернут в Docker (состоит из 3 контейнеров: Python-приложение, Redis, PostgreSQL).

### Быстрый старт
Используйте встроенный скрипт для запуска среды:
```bash
chmod +x start.sh
./start.sh
```
Скрипт автоматически поднимет БД, настроит контейнеры и переведет их в фоновый режим.

### Просмотр логов
Чтобы следить за логами приложения в реальном времени:
```bash
docker-compose logs -f fibo_bot
```
Чтобы посмотреть логи конкретной подсистемы (если вы находитесь внутри контейнера или примонтировали volume `./logs`):
```bash
tail -f logs/strategy.log
tail -f logs/market_engine.log
```

### Управление ботом перезапуском
- Остановка бота: `docker-compose down`
- Пересборка контейнера после обновления кода: `docker-compose up -d --build fibo_bot`

## 🤖 Обучение ML на истории (Bootstrap)

Чтобы бот не торговал "вслепую" (вероятность 50%) с первого дня, рекомендуется собрать исторические данные и сразу натренировать алгоритмы.

Выполните прямо из консоли (находясь в папке бота):
```bash
# Запуск симуляции (если вы запускаете не через Docker, убедитесь, что Postgres работает)
docker-compose exec fibo_bot python scripts/bootstrap_ml.py
```
*Скрипт скачает ~30-60 дней 15-минутных свечей, прогонит их через стратегию, определит, какие сетапы завершились профитом, а какие убытком, обучит модели (XGB, LGBM, LogReg) и сохранит их веса (в папку `ml/models`). При следующем сигнале бот уже будет использовать эти предсказания.*

## ⚙️ Алгоритм работы (Подробно)

Пайплайн работы делится на модули (Engines). Как только в системе появляется новая минутная свеча с WebSocket, поочерёдно запускается следующая цепочка:

1. **`MarketEngine` -> `on_candle()`**  
   Когда свеча выбранного таймфрейма (например, 15m) закрывается, `CandleBuffer` передает массив последних `N` свечей в главное приложение `main.py`.

2. **`FeatureEngine.compute(buffer)`**  
   Данные проходят через математический модуль, который считает:  
   - Индикаторы: `EMA(20,50,200)`, `VWAP`, `RSI(14)`, `ADX(14)`, `Бенды Боллинджера`.  
   - Свечной анализ: Соотношения фитилей к телам (`wick_ratio_top`, `wick_ratio_bot`).  
   - Контекст: Вычисляет время суток и определяет, какая биржа сейчас активна (Asia, Europe, US).  
   Результат упаковывается в объект `FeatureResult`.

3. **`StrategyEngine.analyze(symbol, timeframe, buffer)`**  
   - `RegimeClassifier` смотрит на `ADX` и расположение цены относительно `EMA`, присваивая рынку состояние (UP/DOWN/RANGE).
   - `Wave1Detector` ищет сильный ценовой импульс (Wave 1), где длина непрерывного тренда составляет больше $2.5 \times \text{ATR}$.
   - Если импульс найден, `Wave2FibZone` начинает следить за откатом цены (Wave 2). Она рисует сетку Фибоначчи и ждет, когда цена коснется критической зоны (от 0.5 до 0.618).
   - Если цена в зоне, подключается `StructureBreakDetector` — он ждёт, когда свеча закроется *выше* локального нисходящего максимума (для лонга) — это подтверждение разворота.
   - Как только происходит пробой, `SignalGenerator` рассчитывает уровни:
     - `Entry`: Захватывает текущую цену.
     - `Stop Loss`: Ставится ниже точки начала Wave 1 (или с небольшим отступом).
     - `Take Profit 1,2,3`: Считаются как математические расширения Фибоначчи (`1.272`, `1.618`, `2.0`).

4. **`RiskEngine.validate(signal, features)`**  
   Сигнал готов, но можно ли входить?  
   - **Volatility Filter**: Проверяется, не находимся ли мы в аномальной пиле (текущий ATR < $3 \times$ MA(ATR)).
   - **Daily Loss Filter**: Бот делает запрос в PostgreSQL (`db_manager`) -> не превысил ли бот за день 3 убытков подряд или 5% просадки PnL.
   - **Exposure Manager**: Бот спрашивает у Redis (`redis_manager`) -> нет ли уже максимального количества (3) открытых сигналов.
   - **Position Sizer**: Расчет безопасного % от депозита. Если стоп-лосс далеко, позиция должна быть маленькой. Если близко — можно войти крупнее (динамический Risk=1%).

5. **`MLEngine.predict_probability(features, signal)`**  
   Сигнал отправляется в нейронку. Модели (XGBoost + LightGBM) извлекают матрицу `FeatureResult` и сопоставляют их с похожими сделками из прошлого. Модуль возвращает вероятность от 0% до 100%, что сделка достигнет `Take Profit 2`.

6. **`ChartService.generate_chart(...)`**  
   Специальный сервис конвертирует свечи в Pandas DataFrame и через библиотеку `mplfinance` "в фоне" (без графического интерфейса ОС) рисует свечной график. Накладываются линии Фибоначчи, разноцветные уровни SL/TP, зеленая/красная зона EntryBox и Watermark с R:R и процентами ML. Картинка сохраняется на диск.

7. **`TelegramService.broadcast_signal(signal)`**  
   Финальный аккорд. Бот извлекает сгенерированную картинку графика, форматирует текстовый объект `TradeSignal` в красивое HTML сообщение (с эмодзи), добавляет кнопку "Рекомендованная маржа" и присылает уведомление администратору в Telegram. Картинка сопровождается полным техническим обоснованием (`explanation`).

Для управления ботом прямо в Telegram предусмотрено постоянное меню кнопок внизу экрана: **📊 Статус**, **⏸ Пауза**, **▶️ Возобновить**. Команда Статус достаёт PnL (за 24ч) из БД. Пауза записывает стейт в Redis, блокируя прохождение сигналов через `RiskEngine`.
