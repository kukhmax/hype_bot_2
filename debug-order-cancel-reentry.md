# Debug Session: order-cancel-reentry

- Status: OPEN
- Started: 2026-05-20
- Symptoms:
  - После отмены ордера открывается позиция.
  - На бирже не выставляются TP/SL после открытия.
  - При постановке ордера иногда получается слишком большой спред.
  - Пересечение линий аллигатора должно быть до последних кластеров, а не после.
- Scope:
  - `bill_bot/services/execution.py`
  - `bill_bot/services/execution_live.py`
  - `bill_bot/services/strategy.py`
  - `bill_bot/main.py`
  - `bill_bot/services/telegram_bot.py`
- Hypotheses:
  - Локальный ордер после ручной отмены не успевает удалиться из состояния, и `on_candle()` повторно открывает позицию из stale state.
  - После открытия позиции `sync_state()` не находит корректные `PendingOrder`/trigger orders и записывает `SL/TP = 0`, из-за чего на биржу ничего не ставится.
  - Новый расчёт entry/stop от последних кластеров даёт слишком широкий диапазон, потому что отсутствует нижняя/рабочая граница фильтра по ATR и/или берутся не те последние кластеры.
  - Проверка пересечений аллигатора относительно кластеров сейчас считает неверный временной диапазон и допускает пересечения после сетапа.
  - Ручная отмена в Telegram отменяет биржевой ордер, но не полностью защищает от последующего события открытия/синхронизации по уже исполненному fill.
- Plan:
  - Собрать runtime evidence через debug instrumentation.
  - Воспроизвести сценарии по логам.
  - Подтвердить или отвергнуть гипотезы.
  - Внести минимальный фикс после подтверждения причины.
- Progress:

    - `D`: проверка пересечений аллигатора до сетапа
    - `E`: проверка спреда между последними кластерами в `ATR`
