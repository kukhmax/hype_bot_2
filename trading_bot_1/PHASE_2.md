4. Создать скрипт для оптимизации параметров (Grid Search).

## Реализованный функционал

### 1. Feature Engineering (`core/features/indicators.py`)
- Написан класс `FeatureEngineer`.
- Расчет следующих индикаторов реализован через чистые векторные вычисления Pandas (для гарантии совместимости с новой версией Python 3.14):
    - **EMA** (Экспоненциальная скользящая средняя)
    - **RSI** (Индекс относительной силы)
    - **ATR** (Средний истинный диапазон)
    - **Bollinger Bands** (Полосы Боллинджера)
    - **ADX & DI/D-** (Индекс направленного движения)
- Очистка от NaN значений на старте для корректного старта движка.

### 2. Docker-инфраструктура
- Подготовлен минималистичный и оптимизированный `Dockerfile` на базе `python:3.11-slim`.
- Дополнен `docker-compose.yml` (теперь включает поднятие локального Redis и самого торгового приложения `bot`).
- Синхронизирована настройка `REDIS_URL` через внутреннюю сеть Docker.

### 3. Торговые Стратегии (`core/strategies/`)
Реализованы три логики:
1. **Trend Pullback Strategy**: 
    - *Суть:* Торговля по тренду (EMA50 > EMA200), вход на откатах к EMA21 + фильтр по зонам RSI. Выход по Risk-Reward (SL = 1.5 ATR, TP = 2 R).
    - *Тест:* Пройден на 15m таймфрейме `SOL_USDT`.
2. **Volatility Breakout Strategy (Scalping)**:
    - *Суть:* Вход в сделку после сужения полос Боллинджера (консолидация) на пробоях трендовых границ. Сила тренда подтверждается по ADX.
    - *Тест:* Пройден на 5m таймфрейме (130+ входов в условиях волатильности).
3. **Liquidity Sweep Strategy (Reversal)**:
    - *Суть:* Ловля ложных пробоев (сквизов/снятия ликвидности) за локальными Low/High (lookback = 20 свечей). Вход при дивергенции/показаниях RSI.

### 4. Модуль Оптимизации (`core/backtest/optimizer.py`)
- Разработан `StrategyOptimizer`, выполняющий **Grid Search** по параметрам стратегий.
- Выполняет бэктестинг всех заданных комбинаций.
- Выдает ТОП результат по метрикам (`ROI`, `Winrate`, `Total Trades`).
- *Тест:* Проведена успешная оптимизация параметров `TrendPullbackStrategy` в Docker-контейнере (перебирались параметры `rsi_threshold`, `sl_atr_mult`, `rr_ratio`). Найдена оптимальная выборка (ROI > 0.48% на 2000 свечей, 100% winrate).
