# Hype Bot (v2) - Trading Bot

## Описание
Торговый бот для алгоритмического скальпинга и интрадей-торговли на бирже MEXC (Futures / Spot). Бот построен на современной асинхронной архитектуре (`asyncio` + WebSockets) и работает внутри Docker-контейнеров с использованием Redis для кэширования тиков и состояния.

Проект состоит из пяти ключевых модулей:
1. **Data Layer**: Сбор потоковых тиков по WebSockets (`wss://contract.mexc.com/edge`) и агрегация "на лету" в свечи 1m/5m/15m через `CandleBuilder`. Для первоначального наполнения датафреймов используется загрузчик исторической даты через REST API MEXC.
2. **Strategy & Smart Filtering**: Высокопроизводительный векторный расчет технических индикаторов на Pandas. В систему встроен **Regime Classifier** (авто-выбор стратегии под фазу рынка) и модуль **Gemini AI Verification**, выступающий вторым пилотом для фильтрации ложных сигналов.
3. **🧠 Ensemble ML Filter** *(NEW)*: Ансамблевый фильтр из 3 ML-моделей (Momentum / Volatility / Structure), работающий между стратегией и AI-верификацией. Модели оценивают качество сигнала с разных углов, а динамический порог адаптируется по результатам последних 100 сделок.
4. **Execution & Risk Management**: Строгие правила для защиты депозита (дневные лимиты просадок, динамический сайзинг), ATR Trailing Stop (умный безубыток) и модуль выставления торговых ордеров с криптографической подписью HMAC SHA256.
5. **Telegram Interface**: Полное управление ботом с телефона через интерактивное меню и FSM настройки.

## 📈 Реализованные Стратегии и Режимы Рынка

**Важно:** Теперь вам не нужно жестко выбирать стратегию. Модуль **Regime Classifier** анализирует индикаторы (ADX, наклон EMA, ширину Bollinger Bands) и автоматически переключает активную стратегию при каждой новой свече в зависимости от фазы рынка!

В систему встроено 3 комплементарные стратегии, заточенные под разные фазы цикла рынка:

### 1. Trend Pullback (Торговля по глобальному тренду на откатах)
* **Идеальная среда:** Систематические или слабые тренды (Strong / Weak Trend).
* **Логика работы:** Сначала бот выявляет глобальный тренд по наклону и пересечению Скользящих Средних (Цена > EMA 200, EMA 21 > EMA 50). Если тренд бычий, бот ожидает локального "отката" цены вниз — момент, когда осциллятор RSI входит в зону перепроданности (RSI < 40), а цена касается EMA 21. Это дает точку входа с отличным соотношением риск/прибыль.
* **Выход:** Стоп-лосс ставится за локальный минимум, умноженный на параметр волатильности ATR (по умолчанию `1.5` \* ATR). Тейк-профит рассчитывается через Risk/Reward ratio (например, `1:2`).

### 2. Volatility Breakout (Пробой волатильности / Скальпинг)
* **Идеальная среда:** Выход из консолидации (High Volatility Expansion).
* **Логика работы:** Фиксирует моменты "сжатия" рынка (сужение канала Bollinger Bands). Как только ширина канала (BB Width) падает ниже заданного порога, бот встает в ожидании "выстрела" цены. Пробитие верхней границы BB открывает Лонг, нижней — Шорт. Сила и истинность пробоя валидируется индикатором направленности ADX (должен быть > 20).
* **Выход:** Скальперский подход. Короткий и жесткий стоп-лосс на случай ложного выноса (`1` \* ATR) и быстрый тейк-профит (Risk:Reward `1.5`).

### 3. Liquidity Sweep Reversal (Снятие ликвидности / Ложный пробой)
* **Идеальная среда:** Боковик, Рейндж (Range).
* **Логика работы:** Классический Smart Money подход. Бот ищет важнейшие локальные Extremes (минимумы/максимумы) за последние N свечей (например, 20). Если свеча пробивает этот важный уровень длинным "хвостом" (тенью), снося стопы толпы, но закрывается обратно внутри диапазона — это признак снятия ликвидности. Вход подтверждается дивергенцией или перепроданностью по RSI.
* **Выход:** Очень короткий стоп-лосс (за самый край хвоста сквизовой свечи) и высокий тейк-профит (до середины диапазона или к противоположной границе боковика).

## 🧠 Ensemble ML — Многослойная ML-Фильтрация Сигналов

Ансамблевый ML-фильтр из 3 лёгковесных моделей, анализирующих сигнал с разных углов. Каждая модель — `LogisticRegression` (scikit-learn), обученная на результатах бэктеста. Модели **не генерируют** сигналы самостоятельно, а дополнительно **фильтруют** сигналы от стратегий.

### Архитектура ансамбля

| Модель | Задача | Ключевые фичи |
|--------|--------|----------------|
| **Momentum Scorer** | Оценка силы и направления импульса | RSI, RSI delta, наклон EMA 21/50, DI+/DI- |
| **Volatility Scorer** | Оценка благоприятности волатильности | ATR, BB Width, BB Position, Volume Ratio |
| **Structure Scorer** | Оценка рыночной структуры | ADX, EMA alignment, BB Squeeze, Higher Highs/Lower Lows |

### Пайплайн сигнала (от генерации до исполнения)

```
Стратегия (Trend Pullback / Breakout / Liquidity Sweep)
    │  BUY / SELL
    ▼
🧠 Ensemble ML Filter        ← НОВЫЙ СЛОЙ
    │  Score ≥ Threshold? → PASS
    │  Score < Threshold? → BLOCK
    ▼
🤖 Gemini AI Verification
    │  APPROVED / REJECTED
    ▼
💰 Execution (Paper / Live)
```

### Динамический порог (Dynamic Threshold)

Порог принятия сигнала **не фиксирован**, а адаптируется по результатам последних 100 сделок:
- **Высокий Win Rate (>60%)** → порог снижается → больше сделок проходит
- **Низкий Win Rate (<40%)** → порог повышается → строже фильтруем

### Включение / Отключение

ML-фильтр **выключен по умолчанию**. Для активации:
```bash
# В файле .env добавить:
ENABLE_ML_FILTER=true
```
Без обученных моделей фильтр работает в режиме **fallback** (пропускает все сигналы, бот работает как раньше).

### Обучение моделей

Модели обучаются на результатах бэктеста:
```bash
# Запустить обучение + сравнительный бэктест
docker compose exec bot python3 -m tests.test_ml_backtest
```

Подробная техническая документация: [`core/ml/ENSEMBLE_ML_PLAN.md`](core/ml/ENSEMBLE_ML_PLAN.md)

## � Полный Цикл Торговли через Telegram

Ниже описан весь процесс от настройки до получения сигналов — шаг за шагом.

### Шаг 1: Первый запуск (`/start`)

При первом общении с ботом вы увидите приветствие и **клавиатуру из 6 кнопок**:

| Кнопка | Действие |
|--------|----------|
| 📊 **Статус** | Показать текущие настройки, активные движки, режим рынка |
| ⚙️ **Настройки** | Выбрать режим (PAPER / LIVE / SIGNALS) и уровень риска |
| ➕ **Добавить пару** | Добавить торговую пару с таймфреймом и плечом |
| ➖ **Убрать пару** | Удалить пару из списка |
| 🧪 **Тест Стратегий** | Запустить бэктест и оптимизацию параметров |
| 🚀 **ЗАПУСК БОТА** / 🛑 **СТОП** | Запуск или остановка торгового движка |

### Шаг 2: Настройка (`⚙️ Настройки`)

Бот запускает пошаговый мастер (FSM). Вы выбираете:

1. **Режим работы** (кнопки):
   - `PAPER (Тест)` — виртуальная торговля, без реальных денег
   - `LIVE (Бой)` — реальная торговля через API MEXC
   - `SIGNALS (Только сигналы)` — только Push-уведомления, без открытия позиций

2. **Риск на сделку** (вводите число): Например `2.0` — 2% от баланса на одну сделку

### Шаг 3: Добавление торговых пар (`➕ Добавить пару`)

Для каждой пары настраивается:
1. **Символ** — например `SOL_USDT`, `BTC_USDT`, `ETH_USDT`
2. **Таймфрейм** (кнопки) — `1m`, `5m`, `15m`, `30m`, `60m`
3. **Кредитное плечо** (кнопки) — `1x`, `3x`, `5x`, `10x`, `20x`

Можно добавить **несколько пар одновременно** — для каждой будет запущен отдельный движок.

**Пример настроенного портфеля:**
```
• SOL_USDT — 15m, 5x
• BTC_USDT — 5m, 3x
• ETH_USDT — 15m, 10x
```

### Шаг 4: Тест стратегий (`🧪 Тест Стратегий`)

Перед реальной торговлей рекомендуется проверить стратегии на истории:
1. Бот скачивает **~3000 свечей** с MEXC REST API
2. Прогоняет все 3 стратегии с сеткой параметров (Grid Search)
3. Возвращает **TOP-3 стратегий** по ROI с рекомендованными параметрами

### Шаг 5: Запуск торговли (`🚀 ЗАПУСК БОТА`)

При нажатии кнопки **ЗАПУСК БОТА** происходит:
1. Для каждой пары инициализируется отдельный `LiveEngine`
2. Поднимается WebSocket подключение к MEXC
3. Загружаются исторические свечи для прогрева индикаторов
4. Если `ENABLE_ML_FILTER=true` — загружаются обученные ML модели
5. Бот начинает слушать поток тиков и формировать свечи

## �🛡 Риск-Менеджмент и Фильтрация
Бок-о-бок со стратегией работает `RiskManager`, выполняющий функции предохранителя:
- **Размер Позиции (Position Sizing):** Никаких входов "на всю котлету" (All-In). Объем сделки рассчитывается как математически строгий процент от текущего свободного баланса USDT (например, `2%`).
- **Ограничение Дневного Убытка (Daily Drawdown Limit):** При страте алгоритм запоминает сегодняшний стартовый баланс депозита. Если суммарный накопленный убыток бота за сессию достигает предела боли (например, `-5%`), бот физически блокирует выдачу новых ордеров.
- **Smart Exit (ATR Trailing Stop):** Как только сделка проходит расстояние, равное изначальному стоп-лоссу (достигает 1R), стоп-лосс автоматически переносится в уровень безубытка.
- **AI Verification:** Прежде чем отправить ордер на биржу, бот шлет данные индикаторов (RSI, ADX, цену) в нейросеть `Gemini-2.5-Flash`. ИИ фильтрует очевидно плохие/опасные входы, работая как цифровой риск-менеджер.
- **🧠 Ensemble ML Filter:** 3 ML-модели анализируют качество сигнала перед отправкой на AI. Динамический порог адаптируется по истории сделок.

## ⚙️ Установка и Инфраструктура (Docker)

Для работы требуются `Docker` и `Docker Compose`. Все зависимости (Redis, Python, Pandas, scikit-learn) уже запакованы в контейнеры.

### 1. Подготовка конфигурации (Ключи и Токены)
Скопируйте `Template` файл с переменными окружения:
```bash
cp .env.example .env
nano .env
```

Внутри `.env` вам нужно заполнить следующие поля:
- `API_KEY` и `API_SECRET` - Ключи для торговли. Создаются в личном кабинете биржи MEXC (раздел API Management).
- `TELEGRAM_BOT_TOKEN` - Токен вашего Telegram бота. Создается в Telegram через чат с **@BotFather** (команда `/newbot`).
- `ADMIN_CHAT_ID` - Ваш личный Chat ID в Telegram (через бота `@getmyid_bot`).
- `GEMINI_API_KEY` - Ключ для модуля AI Verification. Получить бесплатно можно в Google AI Studio.
- `ENABLE_ML_FILTER` - *(Опционально)* `true` для включения Ensemble ML фильтра.

### 2. Сборка и запуск фоновых сервисов
Для сборки образа Trading Bot и поднятия базы Redis в изолированной сети:
```bash
docker compose build
docker compose up -d
```
С этого момента можно общаться с ботом через интерфейс в Telegram!

## 🚀 Команды для Разработчика / Тестировщика (Консоль)

Все команды предназначены для выполнения внутри активного контейнера `bot`. 
Префикс: `docker compose exec bot ...`

### Модульные Тесты (Unit / Integration Tests)
Убедиться, что все внутренности живут и работают:
```bash
# Тест подписки на тики по WebSockets (Streaming)
docker compose exec bot python3 -m tests.test_mexc_ws

# Тест агрегации тиков из WebSockets в свечи 1m/5m внутри Redis памяти
docker compose exec bot python3 -m tests.test_candle

# Проверка модуля Risk Manager (математика убытков)
docker compose exec bot python3 -m tests.test_risk_manager

# Мокап-проверка модуля Экзекуций (подпись HMAC ордеров без отправки на биржу)
docker compose exec bot python3 -m tests.test_executor
```

### Тесты Ensemble ML
```bash
# Unit тесты ML-компонентов (фичи, скореры, ансамбль, порог, fallback)
docker compose exec bot python3 -m tests.test_ensemble_ml

# Integration тест: бэктест → обучение ML → фильтрация → сравнение метрик
docker compose exec bot python3 -m tests.test_ml_backtest
```

### Моделирование и Оптимизация на Истории
Бот умеет находить лучшие настройки стратегии методом Grid Search:
```bash
# Простой прогон Бэктеста
docker compose exec bot python3 -m tests.test_backtest

# Запуск Оптимизатора сеткой
# Переберет параметры (RSI thresholds, StopLoss ratios) и выведет TOP-5 связок по ROI
docker compose exec bot python3 -m tests.test_optimizer
```

## 💰 Торговля в Реальном Времени (Live Engine)

Сердце системы — `LiveEngine`. Он объединяет потоки биржи WebSockets, нарезку свечей `CandleBuilder`, торговые алгоритмы и ML-фильтрацию в единый вечный цикл.

Бот может работать в трех режимах (настраивается в Telegram или через флаги терминала):
1. **🟢 PAPER TRADING (Симуляция):** Бот будет слушать реальные "живые" данные биржи, формировать паттерны и "на бумаге" открывать фиктивные сделки. Идеально для валидации работы на новых монетах без страха потери депозита. Вы получаете PnL отчеты в Telegram виртуально.
2. **🔔 SIGNALS (Только сигналы):** То же, что Paper Trading, но бот даже не эмулирует сделку. Он просто шлёт алерт в Telegram: "Сформирован сигнал в LONG".
3. **🔴 LIVE TRADING (Боевой режим):** Бот начнет использовать реальный баланс на MEXC и дергать ручки API POST `/api/v3/order`.

### Управление через Telegram (Рекомендуется)
Просто нажимайте кнопки в чате с вашим ботом. Он сам сформирует нужные настройки и запустит движок в фоне, отправляя вам уведомления.

### Управление через Терминал (Альтернатива)
Если сервер без графики или Telegram по какой-то причине недоступен, взаимодействие происходит через точку входа `run_bot.py`. Доступные аргументы:
- `--symbol` (строка, дефолт `SOL_USDT`) - торговая пара
- `--tf` (число, дефолт `15`) - таймфрейм в минутах
- `--live` - **ФЛАГ БОЕВОЙ ТОРГОВЛИ!**
*(Стратегия выбирается автоматически благодаря модулю Regime Classifier).*

### Базовый пример запуска (Безопасный Paper Trade)
Учимся торговать эфиром на 5-минутках (без риска, виртуальные ордера):
```bash
docker compose exec bot python3 run_bot.py --symbol ETH_USDT --tf 5
```

### Запуск в БОЕВОЙ ТОРГОВЫЙ СТРИМ (Live Mode)
Подключаем Солану к настоящим деньгам на 15-минутках:
```bash
docker compose exec bot python3 run_bot.py --symbol SOL_USDT --tf 15 --live
```
