# Hype Bot (v2) - Trading Bot MVP

## Описание
Торговый бот для алгоритмического скальпинга и интрадей-торговли на бирже MEXC (Futures / Spot). Бот построен на современной асинхронной архитектуре (`asyncio` + WebSockets) и работает внутри Docker-контейнеров с использованием Redis для кэширования тиков и состояния.

Проект состоит из трех ключевых модулей:
1. **Data Layer**: Сбор потоковых тиков по WebSockets (`wss://contract.mexc.com/edge`) и агрегация "на лету" в свечи 1m/5m/15m через `CandleBuilder`. Для первоначального наполнения датафреймов используется загрузчик исторической даты через REST API MEXC.
2. **Strategy & Feature Engine**: Высокопроизводительный векторный расчет технических индикаторов (EMA, RSI, Bollinger Bands, ATR, ADX) на чистом Pandas (без лишних C++ зависимостей вроде `ta-lib`). 
3. **Execution & Risk Management**: Строгий свод правил для защиты депозита (дневные лимиты просадок, динамический сайзинг) и модуль выставления реальных торговых ордеров (`MEXCExecutor`) с криптографической подписью HMAC SHA256.

## 📈 Реализованные Стратегии

В MVP встроено 3 комплементарные стратегии, заточенные под разные фазы цикла рынка:

### 1. Trend Pullback (Торговля по глобальному тренду на откатах)
* **Идеальная среда:** Систематические или слабые тренды (Strong / Weak Trend).
* **Логика работы:** Сначала бот выявляет глобальный тренд по наклону и пересечению Скользящих Средних (Цена > EMA 200, EMA 21 > EMA 50). Если тренд бычий, бот ожидает локального "отката" цены вниз — момент, когда осциллятор RSI входит в зону перепроданности (RSI < 40), а цена касается EMA 21. Это дает точку входа с отличным соотношением риск/прибыль.
* **Выход:** Стоп-лосс ставится за локальный минимум, умноженный на параметр волатильности ATR (по умолчанию `1.5` \* ATR). Тейк-профит рассчитывается через Risk/Reward ratio (например, `1:2`).

### 2. Volatility Breakout (Пробой волатильности / Скальпинг)
* **Идеальная среда:** Выход из консолидации (High Volatility Expansion).
* **Логика работы:** Фиксирует моменты "сжатия" рынка (сужение канала Bollinger Bands). Как только ширина канала (BB Width) падает ниже заданного порога, бот встает в ожидании "выстрела" цены. Пробитие верхней границы BB открывает Лонг, нижней — Шорт. Сила и истинность пробоя валидируется индикатором направленности ADX (должен быть > 20).
* **Выход:** Скальперский подход. Короткий и жесткий стоп-лосс на случай ложного выноса (`1` \* ATR) и быстрый тейк-профит (Risk:Reward `1.5`).

### 3. Liquidity Sweep Reversal (Снятие ликвидности / Ложный пробой)
* **Идеальная среда:** Боковик, Рейндж (Range).
* **Логика работы:** Классический Smart Money подход. Бот ищет важнейшие локальные Extremes (минимумы/максимумы) за последние N свечей (например, 20). Если свеча пробивает этот важный уровень длинным "хвостом" (тенью), снося стопы толпы, но закрывается обратно внутри диапазона — это признак снятия ликвидности. Вход подтверждается дивергенцией или перепроданностью по RSI.
* **Выход:** Очень короткий стоп-лосс (за самый край хвоста сквизовой свечи) и высокий тейк-профит (до середины диапазона или к противоположной границе боковика).

## 🛡 Риск-Менеджмент
Бок-о-бок со стратегией работает `RiskManager`, выполняющий функции предохранителя:
- **Размер Позиции (Position Sizing):** Никаких входов "на всю котлету" (All-In). Объем сделки рассчитывается как математически строгий процент от текущего свободного баланса USDT (например, `2%`).
- **Ограничение Дневного Убытка (Daily Drawdown Limit):** При страте алгоритм запоминает сегодняшний стартовый баланс депозита. Если суммарный накопленный убыток бота за сессию достигает предела боли (например, `-5%`), бот физически блокирует выдачу новых ордеров. Торговлю придется возобновлять на следующие сутки после "остывания".

## ⚙️ Установка и Инфраструктура (Docker)

Для работы требуются только `Docker` и `Docker Compose`. Все зависимости (Redis, Python, Pandas) уже запакованы в контейнеры.

### 1. Подготовка конфигурации
Скопируйте `Template` файл с переменными окружения и вставьте туда ключи, сгенерированные в личном кабинете биржи MEXC:
```bash
cp .env.example .env
nano .env
```
Замените `your_api_key_here` на реальные данные.

### 2. Сборка и запуск фоновых сервисов
Для сборки образа Trading Bot и поднятия базы Redis в изолированной сети:
```bash
docker compose build
docker compose up -d
```
С этого момента можно общаться с ботом, "входя" в его контейнер.

Все команды предназначены для выполнения внутри активного контейнера `bot`.

Убедиться, что все внутренности живут и работают:

## 💰 Торговля в Реальном Времени (Live Engine)

Сердце системы — `LiveEngine`. Он объединяет потоки биржи WebSockets, нарезку свечей `CandleBuilder` и торговые алгоритмы в единый вечный цикл.

Бот может работать в двух режимах:
1. **🟢 PAPER TRADING (Симуляция):** Бот будет слушать реальные "живые" данные биржи, формировать паттерны и "на бумаге" открывать фиктивные сделки. Идеально для валидации работы на новых монетах без страха потери депозита.
2. **🔴 LIVE TRADING (Боевой режим):** Бот начнет использовать реальный баланс на MEXC и дергать ручки API POST `/api/v3/order`.

Взаимодействие происходит через точку входа `run_bot.py`. Доступные аргументы:
- `--symbol` (строка, дефолт `SOL_USDT`) - торговая пара
- `--tf` (число, дефолт `15`) - таймфрейм в минутах
- `--strategy` (текст: `trend` / `breakout` / `sweep`) - какая логика активна
- `--live` - **ФЛАГ БОЕВОЙ ТОРГОВЛИ!**

### Базовый пример запуска (Безопасный Paper Trade)
Учимся торговать эфиром на 5-минутках стратегией пробоя:
```bash
docker compose exec bot python3 run_bot.py --symbol ETH_USDT --tf 5 --strategy breakout
```

### Запуск в БОЕВОЙ ТОРГОВЫЙ СТРИМ (Live Mode)
Подключаем Солану к трендовой стратегии на 15-минутках с отправкой настоящих денег:
```bash
docker compose exec bot python3 run_bot.py --symbol SOL_USDT --tf 15 --strategy trend --live
```
