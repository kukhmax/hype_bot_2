# Торговый Бот - Этап 1: Data Layer & Базовый Backtest

В **Фазе 1** мы заложили прочный фундамент системы для сбора данных и тестирования. 

## Что было сделано:

### 1. Архитектура и Базовые модули
* **Инициализация проекта**: Настроен Git репозиторий, создана многослойная структура директорий (`core/data`, `core/strategies`, `core/backtest`).
* **Конфигурация**: Настроен класс конфигурации `core/config.py` с использованием `pydantic-settings` (.env).
* **Логирование**: Реализована система потокобезопасного асинхронного логирования (`core/logger.py`).

### 2. Подключение к потокам данных (WebSocket)
* **Абстрактный WS Клиент**: Создан `BaseWebSocketClient` с логикой автоматического реконнекта и экспоненциальной задержкой. 
* **Коннектор MEXC Futures**: Реализован наследник `MEXCWebSocketClient` для получения "сырых" публичных тиков (сделок) в реальном времени (`sub.deal`). Учтены особенности API биржи (ответы в виде массивов).

### 3. Агрегация свечей и управление состоянием (State)
* **Интеграция Redis**: Добавлен конфигурационный файл `docker-compose.yml` для запуска легковесного Redis-сервера (`redis:7-alpine`).
* **Модуль CandleBuilder**: Разработан класс, который в реальном времени агрегирует поток сделок (тиков) и строит OHLCV свечи заданного таймфрейма (например, 1м, 5м).
* **Отказоустойчивость**: Текущие, формируемые свечи постоянно сохраняются в Redis. В случае падения бота, агрегация продолжится без потери данных с момента последней сохраненной миллисекунды.

### 4. Загрузчик исторических данных (REST API)
* **History Downloader**: Разработан модуль `MEXCHistoricalDownloader`, умеющий скачивать через официальное REST API MEXC историю свечей (k-lines). Это необходимо для расчёта индикаторов, требующих глубины данных (например, EMA 200).
* Загруженные данные автоматически конвертируются в `pandas.DataFrame` со строгой типизацией и обработанным временем для последующего анализа.

### 5. Скелет стратегий и Бэктестер (Engine)
* **Интерфейс BaseStrategy**: Описан базовый класс для всех стратегий (`on_ohlcv`, `prepare_data`).
* **Аналитический движок BacktestEngine**: Реализован базовый симулятор биржи для оффлайн тестирования на основе DataFrame:
  * Прогон стратегии свеча за свечой.
  * Условное исполнение сделок (LONG/SHORT).
  * Поддержка Stop-Loss заявок.
  * Калькуляция комиссии и базовых метрик (Winrate, ROI).
* Создана фейковая тестовая стратегия (`SimpleMAStrategy`) для проверки работы движка (отработки сигналов и стопов).

---

> [!TIP]
> **Итог Фазы 1**: У нас есть надежный поток он-лайн тиков, он склеивается в свечи, страхуется в Redis, и скачивается история для инициализации индикаторов. Любую придуманную логику теперь можно за считанные секунды проверить на истории через наш `BacktestEngine`.
