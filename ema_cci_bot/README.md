### Инструкция по запуску

## Подготовка:

- Убедитесь, что на сервере установлены docker и docker-compose.
- Создайте структуру папок и скопируйте код в соответствующие файлы.

## Настройка:

- Откройте файл bot/config.py.
- Вставьте свой BOT_TOKEN (от BotFather).
- Вставьте свой ADMIN_ID (Ваш цифровой ID в Telegram).
- Отредактируйте MONITORED_PAIRS, если хотите другие пары.

## Запуск:

Находясь в папке проекта (где лежит docker-compose.yml), выполните команду:
```
code
Bash
docker-compose up -d --build
```
-d: запуск в фоновом режиме.
--build: пересборка контейнера (нужно при первом запуске или изменении кода).

## Проверка:

Напишите боту команду /start. Он должен ответить.
Смотрите логи контейнера командой: docker logs -f hyper_ema_strategy_bot. Вы увидите сообщения о том, что бот ждет закрытия следующей 15-минутной свечи.

Как только закроется 15-минутная свеча и условия стратегии совпадут на одной из пар, бот пришлет вам сообщение с графиком и данными для входа.
